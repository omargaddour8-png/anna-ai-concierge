Anna AI Concierge
Anna AI Concierge is a Flutter-based AI assistant that helps users find and connect with local service providers.

Features
💬 AI-powered chat assistant
🎤 Voice input
📷 Camera photo capture
🖼️ Gallery image upload
🤖 Make.com automation integration
🏥 Medical assistance workflows
🔥 Heating service requests
🚿 Plumbing service requests
⚡ Electrical service requests
🌿 Gardening service requests
🚗 Automotive assistance
📋 Lead generation and qualification
💾 Conversation persistence

Project Vision
Anna AI Concierge acts as a digital receptionist and concierge that helps users:

Describe their issue
Upload photos if needed
Receive AI-assisted guidance
Connect with the appropriate professional
Submit service requests and appointments
